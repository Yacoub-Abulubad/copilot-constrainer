# Archived Branch Scopes

This directory contains scope files from merged branches, preserved for historical reference.

Each file is named `YYYY-MM-DD_<branch-name>_SCOPE.md` — the date is when the PR was merged.

## Why keep these?

- They document *why* features were built, not just *what* was built.
- They serve as lightweight Architecture Decision Records (ADRs).
- They help new team members understand the intent behind past changes.
- They give AI agents historical context about what was (and wasn't) in scope for past work.
